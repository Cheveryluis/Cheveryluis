## 🔧 Sobre mí

* Diseño esquemáticos y selecciono componentes para sistemas de electrónica automotriz en PERCOTRONICS, trabajando con bombas de inyección diésel, CAN FD y K-Line.
* Programo microcontroladores en C (dsPIC33AK, ATSAM) desde 2024, con MPLAB X como entorno principal.
* Desarrollo herramientas de gestión, control e instrumentación en LabVIEW.
* Desarrollo software de escritorio en Python (PySide) — TaxiCentral, un sistema de licenciamiento y gestión de clientes/conductores para cooperativas de taxi.
* Colaboro en flujos de trabajo Git/KiCad para diseño de hardware en equipo.
