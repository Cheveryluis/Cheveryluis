## 🔧 Sobre mí

* Programo microcontroladores en C desde 2024 (dsPIC33AK, ATSAM), usando MPLAB X como entorno principal.
* Programo en LabVIEW desde 2024, con buen dominio de la herramienta.
* Diseño esquemáticos y selecciono componentes para sistemas de electrónica automotriz en **PERCOTRONICS**.
* Trabajo con bombas de inyección diésel, CAN FD y K-Line.
* Desarrollo software de escritorio en Python (PySide) para gestión y control — actualmente TaxiCentral, un sistema de licenciamiento y gestión de clientes/conductores para cooperativas de taxi.
* Colaboro en flujos de trabajo Git/KiCad para diseño de hardware en equipo.
